# ADR 0006 — Synthetic stimuli are immutable experimental artifacts

## Status
Accepted for Phase 6.

## Context

Mosaic intends to use explicitly disclosed synthetic candidates to measure attraction preferences under controlled conditions. A generated image is therefore not ordinary presentation content. It is part of the experimental evidence required to interpret a user's response.

If a generator, prompt, seed, quality-control rule, or left/right assignment can be changed after a response is recorded, the historical observation becomes scientifically ambiguous. Storing only a nominal stimulus ID or the latest generated image is insufficient.

## Decision

Mosaic persists the synthetic-calibration chain as distinct records:

```text
stimulus specification
        ↓
generated asset + exact content hash + generation provenance
        ↓
versioned QC adjudication
        ↓
immutable randomized pair assignment
        ↓
immutable user response
```

Each layer has a different meaning and must not overwrite the previous layer.

### Stimulus specification

The exact controllable input is retained with a specification version and SHA-256 identity. Generator coordinates are data, not merely implementation parameters.

### Generated asset

The exact generated bytes are identified by SHA-256 and retained through an asset URI. Generation provenance records the adapter, provider, model, model revision, seed, resolved prompt, and generation parameters.

The generator is accessed through a provider-independent adapter. Switching to a different image provider must not require redesigning the experiment ledger.

### Quality control

QC is an adjudication about an artifact, not a mutation of the artifact. A new QC implementation appends a new versioned QC event. It does not replace the generated asset or erase an earlier decision.

Only an asset accepted by the active QC rule may enter an authored pair.

### Pair assignment

The exact left/right asset IDs, ordinal, randomization seed, and pair-policy version are persisted. A response is interpreted against this stored assignment, never against a newly reconstructed ordering.

### Response

The raw A/B/Both/Neither observation is immutable and idempotently ingested. It references the exact persisted pair.

## Cross-runtime canonical provenance

Experimental provenance must serialize identically in every runtime expected to replay it. Integer-valued provenance that crosses JSON boundaries must therefore either be encoded as strings or remain within the IEEE-754 exact-integer range.

Phase 6 keeps deterministic stimulus and pair seeds in the inclusive range

```text
0 ≤ seed ≤ 9,007,199,254,740,991 = 2^53 - 1
```

and enforces the same bound in the Pydantic wire models and PostgreSQL schema. This is not a randomness requirement; it is a reproducibility requirement. It prevents JavaScript from rounding a seed that Python and PostgreSQL retained exactly, which would make otherwise identical persisted specifications hash differently during replay.

Canonical SHA-256 checks are defined over normalized JSON with sorted object keys, compact separators, and integer-valued floating-point fields normalized to integers before serialization.

## Collision behavior

Deterministic IDs are convenience identifiers, not a substitute for provenance validation. If an attempted create collides with an existing deterministic ID, the server must read the existing record and verify the immutable payload is identical. A same-ID/different-content collision fails closed.

This protects against an implementation changing without the required version increment.

## Phase 6 mock generator

Phase 6 uses a deterministic local PNG adapter. It produces controlled geometric face-card images using only the Python standard library. Its purpose is to prove the artifact, provenance, caching, rendering, and replay architecture without depending on an external AI image service.

The mock images do not claim realism, attraction validity, psychometric validity, or matchmaking validity.

## Consequences

- Historical trials remain interpretable after generator or QC implementations evolve.
- A complete trial can be replayed from persisted experimental metadata.
- A real generative-image provider can replace the mock adapter without changing the persistence contract.
- Cross-language replay cannot silently lose deterministic-seed precision.
- Storage requirements are higher because exact experimental artifacts and provenance are retained.
- Generator/policy changes require explicit version changes rather than silent replacement.
